# 7/8 出局

日期 2026-11-24。范围：只就"密度型 f = η²、supp f ⊂ (−λ,λ)、2λ ≤ 1"这一类，判 7/8 在本类内是否可达。不涉及其他类（例如非密度型、或允许 RH 作前件的系统）。

## 一、口径

`K = f̂`，`Q = f ∗ f`，`Q̂ = K²`。

`C_η = Q(0) + 2∫₀¹ α Q(α) dα`；本项目的换算为精确恒等 **比例 = 2 − C_η**（与 `3/2 − (1/√2)cot(1/√2)` 吻合，无自由参数）。

故 7/8 ⟺ 比例 ≥ 0.875 ⟺ **C_η ≤ 1.125**。

## 二、排除

CCLM（J. Reine Angew. Math. 725 (2017) 143–182, Cor. 14）在本类内给出下界；Lamzouri（arXiv:2609.02882v1 Thm 1.1）把该常数取到极值：

`C_MT = 1/2 + (1/√2)cot(1/√2) = 1.3274992963206…`（取 `f₀(x) = cos(√2x)/(√2 sin(1/√2))` 于 [−1/2,1/2]）。

由此得本类内的**上界**：比例 ≤ 2 − 1.3274992963206 = **0.6725007036794 < 0.875**。

差 0.2025（相对 15.25%）；换算回 C 是 1.125 vs 1.3275。这是不等式，不是估算：在"能用来证的定理"里，1.3275 是地板，1.125 在天花板之下。

## 三、差在哪，不在精度

实测 A 饱和值 1.3078 ± 0.002（H≈40 即饱和），距 C_MT 只差 1.5%；四项残差拆分 +0.0371 / +0.0823 / +0.0016 / +0.0195。也就是说，我们的数值已经贴到定理地板，剩下的 0.2025 不是"再抠一点"能补的。

机制在于可用域：`F(α)` 的 α ≤ 1 段只用 n ≤ T 的 Λ(n)（属 PNT 范围）；α > 1 段需要 n > T 的素数信息，超出显式公式截断。按密度摊平粗估，C ≤ 1.125 需 α 用到 ~8 量级（推断，非事实）。越弱的目标反而要求越深的区间。

## 四、RH 救不了这个方向

我们的定理是单向的：`比例 ≥ 2 − A`。RH 给的是"比例 = 1"，箭头无法倒转成 `A ≤ 1.125`。所以 RH ⟹ 干到 1 ⟹ 7/8 三步不可逆，而"用 RH 办 7/8"属借大办小，且借不到——RH 改的是余项与单重比例，不改 `F(α)` 的可用域。

口径手术必须写明：在**比例口径**下（"单重或在线比例 ≥ 0.875 或 C ≤ 1.125"）RH 定义级兑现 7/8；在**A 口径**下（`A ≤ 1.125`）RH 兑现不了。凡声称"7/8 成立"者，必已隐含 RH 级输入；在不用 RH 的公理集合内，7/8 为假。

## 五、唯一合法的入口

把目标写成条件命题：`(H2′_λ) ⟹ A(λ) ≤ 1 + ε ⟹ 比例 ≥ 1 − ε ⟹ 7/8`（取 ε ≤ 1/8）。即要求 α > 1 段的加权一阶矩 = 1（因 A 是经验平均、除以 N，需求可从"逐点 F(α)=1"降到"加权一阶矩=1"）。这一条是假设，不是本类内的定理，落点在素数侧 n > T 的 Λ 两点相关的 lag 平均。

## 六、可机检的否定命题

骨架：`C_η ≥ C_MT = 1.3275` ∧ `比例 = 2 − C_η` ⟹ `比例 ≤ 0.6725` ⟹ 7/8 在本类内为假。这条不需要任何猜想，是本项目内可直接形式化的否定命题——也是我们与"7/8 口径"彻底分开的机检证据。

## 七、结论

7/8 在本类内定理级出局；继续在 7/8 上抠常数的边际收益恒为零。下一步只有两条：要么把它降格成条件命题（第五节），要么放弃它、直接做干到 1。

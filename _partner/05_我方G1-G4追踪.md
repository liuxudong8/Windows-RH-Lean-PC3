## 三、两个自家发现（比账面上的更重）

**甲 结论内的占位常数**：`s71_main`（Main:1347-1364）的结论是

`pairConstant triKer δ (N_L T) (zerosLChi5UpTo T) ≤ C_MT + C₁ ε + C₂`，而收尾处 `refine ⟨C₁, 2, …⟩` 把 `C₂` 取成 2——因为 `|prime| ≤ 1` 与 `|E/N_L| ≤ 1` 各吞 1。
后果：令 ε→0，得到的是 `A ≤ C_MT + 2`，**不是** `A ≤ C_MT + o(1)`。整条 A 线在这一步丢掉了极限信息；这与档案里 `∧ True` 是同一类手法，只是用的是"和 2"而不是 `True`。

**乙 支线未接通**：`bgs3_pair_expansion` 里素数项直接硬编码 `|prime| ≤ 1`，于是 (L2) 那条半形式化的素数侧链（`primeSum`、Abel 求和、`prime_sum_bound`）根本没接到主定理上。这既是浪费，也是隐患：`siegel_walfisz_chi5` 名义在账、实际不在链。

## 四、与 7/8 出局的互证

7/8 需 `A ≤ 1.125`；而 `C_MT = 1.3275` 已高于它，`s71_main` 更只给 `A ≤ C_MT + 2`。所以 A 线在任何一步都碰不到 7/8——这不是常数没算够，是目标与可用域不相交。
